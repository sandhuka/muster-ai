# User Insights Skill

Understand who the target user is, what problems they have, and how they currently solve them.

## Jobs-to-be-Done

For each target segment, define:

- **When** [situation] **I want to** [job] **so I can** [outcome]
- Layer: functional (get a workout done), emotional (feel accomplished), social (look/feel fit)
- Prioritize by: high importance + low satisfaction with current solutions = biggest opportunity

## Personas

Build 2-3 personas max. Each needs:

- Segment label, demographics, fitness level
- Goals (why they work out at home)
- Frustrations (what's broken with current solutions)
- Current behavior (what they do today — YouTube? Old app? Nothing?)
- Trigger (what would make them try something new)

Likely segments for this product:

- **Time-constrained professional**: 15-20 min windows, wants efficient structured routines, hates decision fatigue
- **Home fitness beginner**: Intimidated by gyms, needs guidance on what to do and when, wants science-backed confidence
- **Multi-discipline explorer**: Likes mixing strength + yoga + breathwork, wants variety without managing multiple apps

Validate or revise these with data.

## Pain Point Mapping

Categorize pains: functional (can't build a proper routine), financial (premium apps too expensive), process (too many steps to start), guidance (don't know which exercises pair together or when to rest). Rate by severity × frequency.

## User Journey

Map: Awareness → Consideration → Activation (first completed routine) → Retention (weekly habit) → Referral. For each stage: what the user does, drop-off risks, opportunities to improve.

The critical moment is activation — the first time a user completes a personalized routine and feels it was built for them.

## Output Format
Document findings in `knowledge-base/research/user-insights.md` using the standard research doc structure:
- **Current State**: 5-10 line summary
- **Findings**: Personas, JTBD, pain points, journey maps
- **Open Questions**: What needs further investigation
- **History**: Dated one-liner entries for major updates
